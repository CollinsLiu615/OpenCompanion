# 快速上手

## 你要准备什么

只有一个：**一个 AI 服务的 API Key**。

不知道怎么弄？以 DeepSeek 为例：
1. 打开 platform.deepseek.com 注册
2. 左侧「API keys」→ 创建
3. 复制那串 `sk-` 开头的字符

## 第一次使用

1. 打开程序（电脑双击图标，或手机装 APK）
2. 会让你填接口地址、Key、模型名 —— 选好服务商会自动填前两项
3. 点「测试连接」，看到「连接成功」再往下走
4. 写一句你想要的角色描述
5. 等 1-2 分钟，AI 会写出完整人设
6. 不满意就改，改完上传头像，点完成

## 常见问题

**测试连接失败，提示 401？**
Key 复制错了，检查有没有多余空格、是不是复制全了。

**提示 404？**
接口地址或模型名不对。注意地址一般以 `/v1` 结尾（智谱例外）。

**提示 429？**
额度用完了或请求太频繁。去服务商后台看看余额。

**人设生成很慢？**
正常，要 1-2 分钟。用便宜的小模型会快一点。

**换电脑/换手机数据会丢吗？**
电脑端数据在 `data/` 文件夹，拷走就行。
安卓端存在 App 内，卸载会丢，建议先在电脑端导出人设文本保存。
